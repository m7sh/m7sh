```man
MUSH(1)                          User Manuals                          MUSH(1)

NAME
     Mohammed Musharaf (m7sh) - Electronics & Communication Engineer, Linux rice artisan & developer.

SYNOPSIS
     mush [--portfolio] [--plugins] [--themes] [--collaborate]

DESCRIPTION
     Mohammed Musharaf is an open-source developer with a deep focus on the Linux Wayland
     ecosystem, specializing in declarative QML status-bar architecture, Hyprland desktop rices,
     and keyboard-centric TUI tooling.

OPTIONS
     --portfolio
          Launches the interactive portfolio site at https://m7sh.github.io/m7sh/
          featuring matrix digital rain simulations, audio effects, and command palettes.

     --plugins
          Installs modular widgets for Omarchy bar including mush.workspace and omarchy-media.

     --themes
          Dispatches aesthetic color schemes across Gruvbox, Velvet Dusk, God of War, and Everpuccin.

     --collaborate
          Signals readiness to pair program, build innovative desktop tools, or contribute upstream.

SEE ALSO
     hyprctl(1), quickshell(1), fastfetch(1), git(1)
```
